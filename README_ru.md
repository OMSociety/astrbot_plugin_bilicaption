## Ключевые возможности

| Возможность | Описание |
|------|------|
| **Извлечение чистого текста субтитров** | Извлекает оригинальный текст субтитров видео bilibili без ИИ-резюме и возвращает его пользователю напрямую |
| **Глубокое прочтение субтитров** | Полные субтитры передаются самому боту, который самостоятельно разбирает / резюмирует содержание видео (опционально, высокий расход токенов) |
| **Умное распознавание ссылок** | Поддержка полных ссылок bilibili / BV-идентификаторов / коротких ссылок b23.tv / коротких кодов с автоматическим разбором |
| **Контроль длины** | Максимальная длина возвращаемых субтитров настраивается отдельно для каждого инструмента, чтобы избежать переполнения контекста |
| **Отправка файла txt** | По желанию полные субтитры сохраняются в файл txt и отправляются в чат |
| **Поддержка авторизации** | После настройки Cookie bilibili доступны полные ИИ-субтитры (API субтитров требует авторизации) |

## Обзор возможностей

### Извлечение субтитров bilibili_caption
Отправьте ссылку bilibili / BV-идентификатор прямо в чат — бот сам вызовет инструмент и вернёт чистый текст субтитров.

### Глубокий разбор bilibili_read
Если включено, когда его просят разобрать видео бот сначала полностью прочитает субтитры и только потом сформулирует ответ.

### Различия двух инструментов

| Особенность | `bilibili_caption` | `bilibili_read` |
|:----|:-------------------|:----------------|
| Назначение | Быстрое извлечение оригинального текста субтитров | Глубокий разбор для чтения самим ботом |
| Возвращает | Текст субтитров для показа пользователю через ИИ | Полные субтитры в поток рассуждений бота |
| Расход токенов | Контролируемый (можно обрезать) | Повышенный (по умолчанию читается весь текст) |
| Включён по умолчанию | Всегда доступен | Выключен, требуется включить в конфигурации |

## Быстрый старт

### Шаг 1: Установка

AstrBot WebUI → Магазин плагинов → поиск `bilicaption`

> **Примечание**: При установке плагина зависимости (bilibili-api-python / aiohttp / aiofiles) устанавливаются автоматически из `requirements.txt`; ручная установка не требуется.

### Шаг 2: Настройка Cookie bilibili (обязательно)

> **Примечание**: API субтитров bilibili требует авторизации, и **без настройки Cookie субтитры получить нельзя** (ИИ-субтитры скрыты от анонимных пользователей). Настройте Cookie перед использованием.

Заполните группу `bilibili_cookie` в конфигурации плагина:

| Поле | Как получить |
|:----|:----|
| `sessdata` | Войдите на [bilibili.com](https://www.bilibili.com) в браузере → F12 → Application → Cookies → скопируйте значение `SESSDATA` |
| `bili_jct` | То же самое, скопируйте значение `bili_jct` |

### Шаг 3: Перезапуск

После настройки перезагрузите плагин в WebUI (или перезапустите AstrBot) и отправьте ссылку bilibili в чат для проверки.

## Описание параметров конфигурации

| Параметр | Тип | По умолчанию | Описание |
|:------|:-----|:-------|:-----|
| `bilibili_cookie.sessdata` | string | `""` | Cookie SESSDATA bilibili (обязательно, API субтитров требует авторизации) |
| `bilibili_cookie.bili_jct` | string | `""` | Cookie bili_jct bilibili |
| `max_subtitle_length` | int | `0` | Максимальное число символов субтитров для инструмента caption; `0` — без ограничения |
| `auto_send_txt` | bool | `false` | Если включено, извлечённые субтитры автоматически отправляются в чат файлом txt |
| `enable_read_tool` | bool | `false` | Включает инструмент глубокого разбора `bilibili_read` (высокий расход токенов) |
| `read_max_subtitle_length` | int | `0` | Максимальное число символов субтитров для инструмента read; `0` — без ограничения (полное прочтение) |

### Быстрый шаблон конфигурации

Заполните панель конфигурации WebUI или ориентируйтесь на следующую структуру (`data/config/astrbot_plugin_bilicaption_config.json`):

```json
{
  "bilibili_cookie": {
    "sessdata": "YOUR_SESSDATA",
    "bili_jct": "YOUR_BILI_JCT"
  },
  "max_subtitle_length": 0,
  "auto_send_txt": false,
  "enable_read_tool": false,
  "read_max_subtitle_length": 0
}
```

## Инструменты, доступные для LLM

Плагин регистрирует 2 инструмента LLM (`bilibili_read` требует включённого параметра `enable_read_tool`). Модель сама решает, когда их вызвать, — просто сформулируйте запрос естественным языком:

```
Пользователь: Извлеки субтитры этого видео https://b23.tv/4bdIZBf
🤖 → bilibili_caption(bvid=https://b23.tv/4bdIZBf)
    [Субтитры] «Краткая история ИИ: от Тьюринга до GPT»
    Всем привет, добро пожаловать в это видео...

Пользователь: Разбери это видео BV1GJ411x7h7
🤖 → bilibili_read(bvid=BV1GJ411x7h7)
    (Полностью читает субтитры, затем самостоятельно формулирует разбор)
```

### bilibili_caption
Возвращает чистый текст субтитров видео bilibili. Если у видео нет субтитров, возвращается соответствующее сообщение.

| Параметр | Тип | Обязательный | Описание |
|:----|:----|:----:|:-----|
| `bvid` | string | Да | BVID / полная ссылка bilibili / короткая ссылка b23.tv, например `BV1GJ411x7h7` или `https://b23.tv/4bdIZBf` |
| `page` | integer | Нет | Номер части, начиная с 1, по умолчанию 1. Для видео с одной частью передавать не нужно |

### bilibili_read (требуется включённый параметр `enable_read_tool`)
Полностью прочитывает субтитры видео bilibili, чтобы бот мог разобрать его содержание. Вызывается, когда пользователь просит резюмировать, проанализировать или оценить видео bilibili.

| Параметр | Тип | Обязательный | Описание |
|:----|:----|:----:|:-----|
| `bvid` | string | Да | BVID / полная ссылка bilibili / короткая ссылка b23.tv |
| `page` | integer | Нет | Номер части, начиная с 1, по умолчанию 1. Для видео с одной частью передавать не нужно |

> **Примечание**: `bilibili_read` возвращает полный оригинальный текст субтитров без каких-либо готовых промптов. Бот сам читает его и решает, как разобрать содержание.

## Часто задаваемые вопросы

### Q1: Нужна ли настройка?

**Да**. API субтитров bilibili требует авторизации; настройте `bilibili_cookie.sessdata` и `bili_jct` (см. [Быстрый старт](#быстрый-старт)).

### Q2: Доступны ли субтитры для любого видео?

Нет. Если автор не загрузил субтитры и у bilibili нет ИИ-субтитров, получить содержимое нельзя — будет выведено сообщение «нет доступных субтитров».

### Q3: Почему нет ИИ-резюме?

`bilibili_caption` по замыслу выполняет только дословное извлечение. `bilibili_read` же передаёт право резюмировать самому боту, без готовых промптов.

### Q4: В чём разница между `bilibili_caption` и `bilibili_read`?

caption быстро возвращает текст субтитров для вас; read передаёт полный текст боту, который сам его прочитывает и выдаёт разбор. read расходует больше токенов, но даёт более качественный разбор. Инструменты не заменяют друг друга; включайте их по необходимости.

### Q5: Чем это отличается от BiliRead?

BiliRead вызывает стороннюю LLM для резюмирования субтитров; этот плагин пропускает стороннюю LLM и либо возвращает оригинальный текст субтитров напрямую, либо использует для разбора самого бота из текущего диалога.
